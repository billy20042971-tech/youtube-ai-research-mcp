# 每日 AI 情報研究報告｜內容生成規範 V3（台灣繁體中文・高價值導讀）

> 目的：將近 72 小時 YouTube 樣本轉化為一般讀者可快速理解、可核對來源、能採取具體行動的 AI 情報。
> 語言：台灣繁體中文。主要閱讀內容一律使用繁體中文；必要的產品、模型、程式庫與平台名稱保留官方英文名稱。
> 證據原則：只依影片內容、描述、逐字稿、留言與可核對資料下結論。不得為了完整度虛構翻譯、功能、案例、數字或操作步驟。

## 1. 報告正文禁止事項

以下不得出現在 Word、PPTX、Notion 正文：
- AI OS、MCP、Agent、State、Recovery、Automation、Workflow、CI、GitHub Run、Execution ID、Notion API、寫回／讀回等工程維運資訊。
- Secret、Token、API Payload、錯誤堆疊、內部路徑、除錯資訊、工程待辦。
- 頻道主的自我介紹、人生經歷、固定片頭片尾、感謝訂閱、按讚、追蹤、加入會員等慣例性宣傳。
- LINE 官方帳號、社群訂閱、課程銷售、折扣碼、聯盟行銷、Amazon 導購、購買／下載 Prompt 雲端檔案等商業導流資訊；除非該項本身是影片研究的核心商業模式，否則不得保留。
- 與研究主題無關的網址、聯絡方式、贊助口播及重複宣傳文字。

技術稽核只存放於獨立 Audit，不得混入讀者報告。

## 2. 語言與翻譯規範（強制）

1. 主要標題、摘要、洞察、工具流程、社群回饋、風險與建議全部使用自然的台灣繁體中文。
2. 日文、英文、簡體中文標題，主要顯示「繁體中文意譯」；原始外語標題僅以較小的「原始標題」欄位附註，不得拿原文充當主要標題。
3. 保留官方產品／模型名稱，例如 Claude Code、Higgsfield、Zazzle、eBay、ChatGPT；首次出現時可用一句繁中說明其用途。
4. 翻譯必須忠於原意，不逐字硬譯，不擴寫原文沒有的承諾。
5. 若來源資料沒有可信的繁中翻譯或語意資訊，明確標示「中文意譯待確認」，不得假裝已完成翻譯；不可把未翻譯原文直接當作中文標題。
6. 社群留言若保留引用，先翻譯成繁體中文；只有在語意不明或關鍵術語需要核對時，才附短句原文。
7. 不使用簡體中文用語；優先採用台灣常用詞，例如「軟體、影片、資料、網路、設定、效能、行銷、營收、帳號」。

## 3. 今日 Top 3 必看推薦（置於報告最前）

列出最多 3 部值得優先觀看的影片，依內容實用性、證據品質、工具／流程具體程度、商業驗證價值及樣本互動訊號綜合排序；不得只按觀看數排序，也不得為湊數硬選。
每部需包含：
- 繁體中文意譯標題、頻道、影片連結。
- 推薦理由標籤，例如「極具實操價值」「AI 商業化真實案例」「技術破局點」；理由必須由來源支持。
- 一句話說明讀者看完能得到什麼。
- 證據強度／限制：只有標題或簡介時，明確標示資料不足。

## 4. 四大正文章節

### A. 🚀 今日 3 分鐘核心趨勢摘要
- 綜合所有有效樣本，提出最多 3 個今日訊號。
- 說明觀察、支持樣本、重要性、證據強度及限制。
- 用一句話回答「今天最值得關注的 AI 變化是什麼？」
- 觀看數只代表觸及，不等於品質、趨勢或市場需求。

### B. 📊 主題分類洞察
分類：AI 副業變現、職場自動化與省時、AI 影音／數位人、產業與投資觀點、其他 AI 應用。
每個有足夠樣本的主題，寫出共同做法、具體工具／關注點、對工作者／教師／創作者的意義，以及尚缺乏的證據。不可只堆疊關鍵字或逐條抄標題。

### C. 🎬 精選影片拆解
挑選 5～10 部真正有內容的影片；有效內容不足時如實減少。每部採用三個固定區塊：

**🎯 核心商業價值**
- 說明解決的問題、目標客群、價值來源、成本／收入模式或效率改善。
- 清楚區分影片展示、作者宣稱與報告分析；未經獨立驗證的營收／銷量不得寫成事實。

**🛠️ 使用的 AI 工具與工作流**
- 列出來源實際提及的工具、版本、用途、輸入／輸出及工具間流程。
- 只依描述、逐字稿或可取得內容；只有標題時寫「來源資訊不足」，不得推測影片操作細節。

**💡 實操建議與注意事項**
- 針對該影片的具體工具或商業模式，提出 1～3 個可執行步驟。例如 Claude Code：確認專案目錄與 Git 狀態、指定單一檔案及驗收條件、檢查 diff 並執行測試；Higgsfield：以同一腳本建立基準素材、固定鏡頭與提示詞比較輸出、檢查授權與商用限制；Zazzle POD：選定單一細分品類、檢查關鍵字與競品、上架少量設計並追蹤曝光／轉換；eBay AI：選定商品類別、核對 AI 生成刊登欄位、人工確認品況／規格／政策後小量測試。
- 範例只在影片確實涉及該工具時使用；不可把範例當成影片已示範的步驟。
- 每一點需有明確對象、操作與觀察指標。禁止「選一個低風險、可在 30 分鐘內驗證的小任務」等空泛套話。
- 若來源沒有足夠細節，明確列出「需要補查的關鍵資訊」，不可硬湊步驟。

每部影片另外以小字附註「原始標題」、頻道、發布日期、觀看／互動數及原始影片連結。

### D. 💬 社群痛點與避坑指南
- 從留言中提煉實際操作困難、重複疑問、失敗經驗、成本與平台風險。
- 排除宣傳、聯盟連結、折扣碼、訂閱導流、無關閒聊、表情符號及頻道主自我宣傳。
- 留言先翻譯為繁體中文；保留具體問題，不保留廣告文字。
- 標示有效留言樣本數與代表性限制；留言不是民調。
- 最後提出 3～5 點與當日影片內容直接相關的避坑提醒。

## 5. 排序與證據規則
- Top 3 與精選影片需綜合內容實用性、具體操作資訊、來源完整度、跨影片佐證、發布時間及互動訊號。
- 不以觀看數單獨決定推薦。
- 區分「來源直接展示」「作者宣稱」「報告推論」「建議讀者自行驗證」。
- 收入、銷量、投資回報、平台政策、工具價格及商用授權需附限制或待查證說明。
- 內容不足時減少篇幅或標示不足，不用通用文字填版。
